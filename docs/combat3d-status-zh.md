# 丧尸塔防 3D 改造记录 — 2026-09-05

> 以下保留首版记录。2026-09-06 的新增资产、覆盖范围和尚未完成项见 [后续美术批次](combat3d-art-batch-2026-09-06.md)。目前累计 Tripo 消耗为 400，最后核实余额为 24,710。

## 已落地的版本

在原 `gdproj` 内使用 **Godot 3.6.3** 接入了可运行的 3D 战斗首版，没有创建 Godot 4 工程。启动项目、选角色和武器后自动进入 3D 战斗；项目根目录的 `launch-3d.cmd` 使用本机已安装的 Godot 3.6.3 启动。F8 可临时切回原 2D 画面对照。

战斗中使用实际 3D 模型、骨骼动画、相机、灯光和阴影。原来稳定的平面移动、碰撞、伤害、波次、掉落与商店继续工作；菜单和 HUD 保留 2D。这个方案适用于当前固定英雄、顶部刷怪的竖屏塔防玩法。Godot 3 具备所需的 [3D 场景能力](https://docs.godotengine.org/en/3.6/tutorials/3d/introduction_to_3d.html) 和 [定向光／阴影](https://docs.godotengine.org/en/3.6/classes/class_directionallight.html)，目前没有必须升级 Godot 4 的技术原因。

## 工程覆盖

- 3D 商场通道：平铺地面着色器、灯带、边缘设施、封锁路障、定向光和阴影。
- 幸存者待机；丧尸行走速度随原战斗移动速度调整；对象池隐藏／复用同步到 3D。
- 普通、重型、冲锋、远程、支援等敌人通过体形和配件区分。
- 近战刀刃、长柄、锤类及远程枪械、能量、投射类武器使用程序化立体造型，跟随原武器位置和攻击姿态。
- 立体子弹、敌方弹幕、爆炸、植物、炮塔、宠物、材料与消耗品。
- 命中、暴击、防护、燃烧、治疗、升级、死亡特效；敌人攻击时显示立体预警标记。
- 3D 与原 Camera2D 保持地面投影一致，并修复离屏纹理在 HUD 中上下颠倒的问题。
- 特效使用独立随机数生成器，避免消耗原玩法随机序列。

## 尚未完成的美术工作

当前是**可玩首版，不是全部美术已完成的最终版本**。现有可选角色共用幸存者基础模型；大量武器、环境件、宠物和敌人配件采用程序化 3D 造型。首领目前复用放大的丧尸基础体，并没有独立制作全部首领的 Tripo 模型。角色专属服装、武器精模、首领动作、更多命中特效层次与商场叙事细节仍需进一步制作和验收。

会员剩余时间内，优先次序应为：独立首领与重型／远程丧尸 → 主要可选幸存者 → 常用枪械和近战武器 → 商场场景件。每批先统一比例、朝向、拓扑和材质，再做骨骼、动画、GLB 本地导出和实战检查。后续可从本记录和 `gdproj/combat3d/README.md` 接续，沿用已获授权的积分额度。
