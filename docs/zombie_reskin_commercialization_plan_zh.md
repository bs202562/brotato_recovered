# 《尸潮夜班》商业化换皮方案

> 方案边界：尽量保留现有竞技场生存、自动攻击、多武器、波次结算和商店构筑框架，重点重做题材包装、美术资源和基础命名。

## 一、前置结论与版权风险

“僵尸题材 + 更换全部美术与命名”具备商品化潜力，但当前恢复工程不能在未确认授权的情况下直接商业发布。

当前项目中仍明确包含 `config/name="Brotato"`，并保留了原作角色、武器、UI、音效和代码结构；项目根目录也没有发现能够授权商业使用的许可证文件。

- 如果已经取得合法授权，可以直接采用本方案的换皮路线。
- 如果没有授权，本工程只能作为内部玩法参考。正式产品应重新实现代码，并彻底重做美术、文字、UI布局、关卡节奏和内容组合。
- 仅替换图片和名称，仍可能因为代码、视听表达、角色设计和整体呈现高度相似而产生风险。
- 上线前应由熟悉游戏知识产权的律师审查代码、美术、音乐、字体、插件和外包合同的权属。

参考资料：

- [WIPO：电子游戏版权](https://www.wipo.int/en/web/copyright/activities/video_games)
- [WIPO：电子游戏与知识产权](https://www.wipo.int/en/web/wipo-magazine/articles/video-games-and-ip-a-global-perspective-38773)

## 二、产品定位

### 产品名称

- 中文名：**《尸潮夜班》**
- 英文名：**Dead Shift: Mall Lockdown**

### 一句话卖点

> 商场封锁后的最后一个夜班，拿起货架上的一切，撑到救援抵达。

### 世界观

- 场景：被封锁的巨型购物中心。
- 玩家：被困在商场里的普通职业者。
- 武器：枪械、消防器材、五金工具、厨房用品和实验设备。
- 商店：每波结束后进入“幸存者仓库”。
- 货币：废料。
- 经验：病毒样本。
- 目标：坚持20个封锁阶段，等待屋顶救援直升机。

这个方向能够承接现有“竞技场、自动攻击、六武器、波次商店”的玩法框架，同时比泛化的军事打僵尸题材更容易形成视觉记忆。

市场参考：

- [Brotato Steam页面](https://store.steampowered.com/app/1942280/Brotato/)
- [Yet Another Zombie Survivors Steam页面](https://store.steampowered.com/app/2163330)

## 三、美术方向

推荐采用“欧美漫画式末日卡通”，不采用写实或廉价像素风。

- 45度俯视2D手绘。
- 粗轮廓、硬阴影、少量颗粒纹理。
- 人物头身比约1:2.5，避免沿用土豆形身体和多手持武器的原作轮廓。
- 僵尸按职业和商场区域区分，例如保安、厨师、清洁工、顾客、快递员和实验员。
- 血液使用偏暗色彩，攻击命中特效使用高亮橙红色，兼顾爽感与直播展示。
- 武器图标统一使用斜45度构图，但不沿用原作的品质边框和背景样式。
- UI采用“应急广播屏幕 + 黄色警戒胶带 + 超市价签”的完整视觉体系。

### 武器品质表现

| 等级 | 新名称 | 视觉表现 |
|---|---|---|
| I | 临时拼装 | 胶带、锈迹、裸露零件 |
| II | 加固改装 | 金属护板、黄色标记 |
| III | 战术强化 | 黑色部件、红色识别灯 |
| IV | 原型科技 | 白色陶瓷装甲、蓝色能量核心 |

不能只给同一张武器图片换颜色。每次升级至少应让轮廓、枪口、弹匣或附加模块发生变化。

## 五、属性升级包装

现有工程包含20类升级，可以重新包装成六个身体装备区域。升级界面可直接画成人体装备图，提高题材一致性和商品感。

| 部位 | 包含属性 | 示例名称 |
|---|---|---|
| 头部 | 精准、暴击率、暴击伤害 | 校准目镜、威胁分析器、处决模块 |
| 双臂 | 攻速、近战伤害、远程伤害 | 肌力束带、液压腕甲、后坐力支架 |
| 胸甲 | 最大生命、护甲、生命恢复 | 防咬内衬、陶瓷插板、凝血泵 |
| 循环系统 | 吸血、伤害百分比、异常伤害 | 肾上腺导管、污染适应剂、电弧电池 |
| 腿部 | 移速、闪避 | 越障护膝、弹性外骨骼 |
| 背包 | 搜刮、幸运、工程、范围、武器槽 | 磁力拾取器、工具无人机、扩展枪架 |

四级升级名称统一为：

1. I级：简易
2. II级：加固
3. III级：战术
4. IV级：军规

例如“最大生命升级”可以包装为：

1. 简易防咬内衬
2. 加固防咬内衬
3. 战术防咬内衬
4. 军规防咬内衬

| 五金店员 | 工程装置 | 工具腰带、焊接面罩 |

## 九、美术资源规模

当前项目约包含：

- 63个基础武器家族。
- 50个基础角色目录。
- 201个普通物品数据。
- 20类升级。
- 约140张武器图片。
- 约637张物品图片。
- 约206张单位图片。
- 约196张UI图片。

因此，“全部换皮”接近一次完整的2D游戏美术制作，而不是几十张图标的工作量。

### 建议首发规模

- 12名幸存者。
- 24种武器，每种4级视觉变化。
- 60件普通道具。
- 20类升级图标。
- 8种普通僵尸、3种精英和3个Boss。
- 2张地图主题：商场中庭、地下停车场。
- 1套完整UI。
- 25套主要视觉特效。
- 30个关键音效。
- 8张Steam商店宣传图。
- 1支游戏预告片。

### 粗略预算

以下为国内独立游戏外包的估算区间，最终价格取决于画师水平、动画帧数、修改次数、是否包含源文件以及权利买断范围。

| 制作品质 | 预算估算 |
|---|---:|
| 可上线基础品质 | 人民币8万—15万元 |
| 具有明显商店竞争力 | 人民币18万—35万元 |
| 高质量动画、宣传片和多语言商店素材 | 人民币35万—60万元 |

以上预算不包含程序重写、音乐、发行、税费和法律成本。

所有外包合同必须明确：全球商业使用权、修改权、宣传使用权、源文件交付、是否独占、字体和素材来源，以及生成式AI的使用情况。

## 十、售价与发行方式

- 平台：PC Steam买断制。
- 建议国区定价：人民币22—28元。
- 建议国际基础价格：4.99—6.99美元。
- 首发折扣：九折。
- 免费Demo：3名角色、8种武器、前8个封锁阶段。
- 首发不建议加入广告、抽卡或付费数值。
- 后续DLC可加入医院、地铁站等区域，以及相应角色、敌人和武器。

### Steam商店前三张截图

1. 大规模尸潮和高密度火力效果。
2. 武器拼装与升级选择界面。
3. 不同职业幸存者的构筑差异。

### 内部立项目标

- Demo好评率达到80%以上。
- Demo平均游玩时长达到30分钟以上。
- 正式发布前积累5,000—10,000个愿望单。

以上为内部管理目标，不构成销量保证。

## 十一、建议执行顺序

1. 确认代码和全部原始资源的合法来源；没有书面授权则不基于当前工程直接发行。
2. 制作一张商场场景、一名保安、四种武器和三种僵尸的美术垂直切片。
3. 使用垂直切片制作Steam胶囊图和15秒战斗视频，测试视觉点击率和玩家反馈。
4. 测试结果成立后，再制作12名角色、24种武器的首发内容。
5. 上线Demo，根据数据和反馈扩充道具、Boss与第二张地图。
6. 上线前进行知识产权、平台素材、字体、音乐、第三方插件和隐私合规审查。

## 十二、最终建议

不要把预算平均分配给63种武器和50名角色。优先把12名角色和24种武器做到让玩家一眼认出《尸潮夜班》，比制作一套内容庞大、但看起来像廉价《Brotato》换皮的产品更有商业机会。

首个决策节点不是“是否把所有资源都换完”，而是：

> 一张场景、一名角色、四种武器和三种僵尸，能否建立独立且有吸引力的视觉身份。
