# 角色调试工作台

在 Godot 编辑器中打开并运行：

`res://tools/character_workbench/character_workbench_launcher.tscn`

工作台复用真实的 `main.tscn`、`RunData`、武器与敌人逻辑。角色切换时会自动重载测试场；等级可直接修改；角色视觉节点支持每次 45° 快速旋转。

“塔防测试模式”会固定角色位置，并按指定间隔从地图边缘持续加入敌人刷新队列。活动普通敌人上限为 80，防止调试时失控。

“技能 / 特效触发”按钮提供受击、回血、武器冷却和舞蹈等通用测试动作。角色被动没有统一的主动播放接口，因此其实际效果仍由真实战斗事件触发；当前角色的效果文本会显示在面板中。
